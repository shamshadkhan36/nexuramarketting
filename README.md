# NEXURA Creative & Growth Studio — Agency Website

A world-class, modern, high-converting digital marketing and creative graphic design agency website. Built with a pristine **White / Light Luxury Aesthetic**, electric gradient accents, subtle glassmorphism, responsive micro-interactions, an interactive budget calculator, dynamic portfolio filtering, high-conversion inquiry forms, and a seamless **White / Dark Theme Switcher**.

## 🚀 Quick Start / Local Preview

You can open `index.html` directly in any web browser, or launch a local lightweight development server:

```bash
# Using Python
python -m http.server 8000

# Or using Node / npx
npx serve .
```

Then visit: `http://localhost:8000`
